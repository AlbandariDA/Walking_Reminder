# Walking Reminder 🚶‍♂️💻

A smart tool that reminds you to get up and walk every hour. It keeps you healthy and focused during long working hours.

## How it works ⚙️
- Runs in the background.
- Triggers a pop-up reminder every 60 minutes.
- Helps you maintain posture and stay active.

## Built with 🛠️
- Python
- customtkinter
